## 説明文（4000文字以内）
```
DayList は、予定（カレンダー）とやること（ToDo）を、ひとつにまとめて管理できるシンプルなアプリです。
機能を詰め込みすぎず、「今日なにをすればいいか」がひと目でわかることを大切にしました。

■ こんな方に
・カレンダーとToDoを別々のアプリで管理するのが面倒な方
・シンプルで軽く、毎日開きたくなるアプリが欲しい方
・ログインや会員登録なしで、すぐ使いたい方

■ 主な機能
・ホーム画面で「近日のやること」「近日の予定」がひと目でわかる
・月間カレンダー：日付をタップしてその場で予定を追加
・週間予定表：一週間を時間割のように俯瞰
・やることに締切・カテゴリー・優先度を設定、期限切れも自動で表示
・予定とやることを紐づけて管理
・メモに写真を添付
・5つのカラーテーマ＋好きな壁紙を設定
・検索・絞り込み・データのバックアップ（書き出し／読み込み）

■ プライバシー第一
・アカウント登録は不要です
・入力したデータは、すべてあなたの端末の中だけに保存されます
・個人情報の収集・送信・共有は一切ありません
・アクセス解析や広告トラッキングもありません

シンプルだけど、毎日の予定とやることにはこれで十分。
DayList で、今日を気持ちよく始めましょう。
```
